# Jira Work Reports Guide

Это руководство по настройке и использованию функционала генерации отчётов по работе из Jira.

## Возможности

- Автоматическое подключение к Jira API
- Поиск задач, в которых пользователь участвовал за определённый месяц
- Генерация отчёта на основе шаблона Word
- Отправка готового отчёта через Telegram бот

## Настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Конфигурация Jira

Добавьте следующие параметры в `bot/config.env`:

```env
# Jira Configuration
JIRA_SERVER=https://your-company.atlassian.net
JIRA_USERNAME=your_username@example.com
JIRA_API_TOKEN=your_jira_api_token
JIRA_PROJECT_KEY=PROJECT
REPORT_AUTHOR=Your Name
```

#### Получение API токена

1. Войдите в Atlassian Cloud
2. Перейдите в Account Settings → Security → API tokens
3. Нажмите "Create API token"
4. Скопируйте токен в параметр `JIRA_API_TOKEN`

### 3. Подготовка шаблона

Убедитесь, что файл `resources/report_work_template.docx` содержит:
- Плейсхолдер `MM` для номера месяца
- Плейсхолдер `yyyy` для года

## Использование

### Через Telegram бот

```
/report september
/report august
/report декабрь
```

### Через командную строку

```bash
python jira_report_generator.py september
```

## Поддерживаемые форматы месяцев

**Английский:** january, february, march, april, may, june, july, august, september, october, november, december

**Сокращения:** jan, feb, mar, apr, may, jun, jul, aug, sep, oct, nov, dec

**Русский:** январь, февраль, март, апрель, май, июнь, июль, август, сентябрь, октябрь, ноябрь, декабрь

## Алгоритм работы

1. **Парсинг месяца** - определение номера месяца и года
2. **Подключение к Jira** - аутентификация через API токен
3. **Поиск задач** - JQL запросы для поиска задач пользователя:
   - Задачи, где пользователь является исполнителем
   - Задачи, созданные пользователем
   - Задачи, в которых пользователь оставлял комментарии
4. **Обработка шаблона** - замена `MM` на номер месяца, `yyyy` на год
5. **Добавление задач** - вставка списка задач в формате `(<task>)<title_task>`
6. **Генерация отчёта** - сохранение файла с именем `{автор}_work_report_{месяц}_{год}.docx`


## Устранение неисправностей

### Ошибка подключения к Jira

- Проверьте URL сервера Jira
- Убедитесь, что API токен корректный
- Проверьте интернет соединение

### Шаблон не найден

- Убедитесь, что файл `resources/report_work_template.docx` существует
- Проверьте права доступа к файлу

### Не найдены задачи

- Убедитесь, что у пользователя есть задачи в указанном месяце
- Проверьте права доступа к проектам в Jira

## Примеры команд

```bash
# Генерация отчёта за сентябрь
/report september

# Генерация отчёта за август (русский)
/report август

# Сокращённое название месяца
/report sep
```

Готовый отчёт будет отправлен в чат и сохранён в папку `reports/`.
